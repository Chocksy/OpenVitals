Home v3 — toward the inspiration

Same data, same type families, same mono-for-numbers rule. What changes is the surface: a warm grey canvas, tonal panels with no 1 px borders, pill radii, big light numbers, status carried as light instead of as a chip, and a ruler where the range bar used to be. One lime accent per screen, on the thing you can act on.

Real values from the test user: markers 26 · 19 · 7, HbA1c 5.6 %, TPO 320, vitamin D 19, ALT 34, ferritin 22, LDL 142. Hashimoto's confirmed at 95 %, insulin resistance likely at 97 %.

The ruler — what replaces the range bar

One component, four states. Thick rounded track, the normal band as a quiet tint and the optimal band a shade stronger, the value as a big circular marker with a white ring, and the number printed above it every time. The axis break is a real gap in the track, not a // drawn on a continuous bar, so the scale never lies about distance. The sentence underneath carries exactly one coloured phrase.

06

Cost to build

Everything on this page is CSS and inline SVG on the tokens already in globals.css. No chart library, no canvas, no new dependency. What each piece actually costs:

HERO A

Two gradient tiles

Cheapest thing here. Two divs, one radial gradient each, a grain overlay as a data URI, and the tick ruler is a repeating-linear-gradient with one absolutely positioned marker. Needs one new number from the API: the count of "things to fix", which is just the graded conclusions already on the page. The biological age tile needs the gap value, which the engine computes today. No new state, no new fetch.

HERO B

Wide status tile with the timeline

Same tile, plus real work behind the strip. The dots need a query for draw dates and Apple Health sync days over a window, bucketed to x positions, and the floating pill needs a trend number ("+3.2 last 30 days") that does not exist yet. That is a small server function over the graded markers, and it has to be honest about thin data: fewer than two draws and the pill has nothing to say. The rendering itself is absolutely positioned spans with two custom properties each, so it stays cheap once the numbers exist.

RULER

The range bar replacement

The big one, and worth it. Four states out of one component: in range, borderline, far outside with a real gap in the track, and a target with a hatched pace zone. The percentages are the only hard part, and the current range bar already computes them. Two changes to that math: the axis break becomes two track segments with their own scales instead of one continuous bar with a drawn symbol, and the value label needs an alignment flag near the ends so it never leaves the track. The bands, the ring, the ghost dot and the ticks are pure CSS on existing colour tokens.

SYSTEMS

Quiet pill list

Almost free, and it deletes code. The rings and status chips come out, and each row becomes a four column grid that folds to two lines under a container query. The only new value is the driving marker name per system, which the systems page already picks to decide the state. Status words replace colour as the primary signal, so the list still reads with colour vision differences and in print.

LEDGER

Tonal card with evidence glyphs

Structure unchanged, so the risk is low. The bracket labels become glyph chips: filled dot plus a grade letter for science, half dot for opinion, hollow dot for anecdotal. The glyph needs the existing tooltip pattern from .ov-term attached to it, including the edge aware placement, otherwise the meaning is lost on touch. Keep a text label next to the glyph for opinion and anecdotal, because a shape alone is not an accessible label.

MOBILE + DARK

390 px and the flipped canvas

Mobile costs one container query per component rather than a page of breakpoints, since the tiles and rows already size from cqi. Dark costs a token block: canvas, two surface steps, track, three ink levels. One trap to respect: the marker ring is the panel colour, not white, so it has to read from a variable in both themes. The gradients keep their hue and drop light rather than being redefined.

THE PICK

Hero B, and the ruler everywhere

B earns the space because the timeline is the only part of the home screen that moves on a day with no lab results, which is most days. A is the safe fallback if the trend number cannot be made honest. The ruler should ship regardless of the hero decision: it is the piece that changes how a value reads, and it replaces a component that exists today rather than adding one.

Where the numbers come from

Real: the four evidence rows and their grades, effect sizes and intervals — Gärtner 2002 (RCT, n = 36, −21 %, 95 % CI −34 to −7), Hollowell 2002 (NHANES III, n = 17 353, OR 8.4, 6.9 to 10.2), Vanderpump 1995 (cohort, n = 2 779, RR 3.0, 2.1 to 4.3), Wang 2015 (meta-analysis, 20 sets, OR 1.6, 1.2 to 2.1) and the sardines anecdote graded ○ E; the likelihoods 95 %, 97 % and 77 % and the markers behind them; the 612 genome variants; 52 markers with a value; five draws; 17 protocol items; six chat threads; two questions worth answering; the four settled predictions and their resolved values (ALT 34 U/L, LDL 142 mg/dL, TPO 320 IU/mL, HbA1c 5.6 %); the diagnostics rows, including “fitness: low” having no evidence row behind it, which is exactly what elements-v3 already said about it.

Illustrative: the run ids and timestamps (curator-0217 to 0219), the claim counts per run (148 / 96 / 0 in, 31 / 12 / 0 minted), the 1 284 evidence rows and the twelve parameter values on the Brain form. The four-move tree uses the engine's real endpoints, 0.50 to 0.95, and real intermediate arithmetic.

Build cost

Replaces: the chrome of /brain (1 562 lines), /hkb (1 174 lines) and /admin. The tabs become the sliding pill, the ~6 selects and ~6 number inputs become the system's fields, the scenario and hypothesis cards become the tile, the badges become state words, the eleven tables become one table with a sticky first column, and the buttons become ink, quiet and text.

New: nothing. No feature is added, removed or renamed on these three pages. The move tree gains the likelihood axis it was already implying.

Deletes: every filled badge, the second tab style, and the per-page ad-hoc table CSS. The pages themselves are never removed.

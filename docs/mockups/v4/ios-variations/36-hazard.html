Variation 36 · Hazard

Seven markers are shouting.
So the screen shouts back.

A neubrutalist book-shelf kit lent this one everything it owns: a flat orange ground, 3 px black rules on every edge, a 6 px hard shadow that never blurs, and display type set in a black condensed face at sizes the rest of the folder would call rude. The genre stickers become the four bands. The shelf rail becomes the goals. Off is drawn as hazard tape, because on this screen nothing whispers.

02Today, with no goal on file Nothing is greyed. The slab is replaced by a black poster and three markers volunteering for the job.

03The same screen, inverted The source kit is a light orange one, so the third frame is the dark invention: black ground, white rules, the shadow turned purple.

Colour rule

Three accents, each with one job and no second job. Cyan is in range. Yellow under hatching is out of range. Purple is the only thing you can press: marker names, the section link, the add button, the goal call to action. Nothing else is coloured, which is what keeps a four-colour screen legible.

Design, data & interaction notes

A different information architecture
Whole you connects the domains; Today holds actions and logging; Ask is always available. Details, plan scenarios, original records and connections sit one level deeper. Rings use explicit denominators; the cycle dial represents time, never an achievement goal.

Cycle context belongs to the person
Choose regular tracking, irregular cycles, hormonal contraception, perimenopause, menopause or off. Calendar timing is estimated, ovulation is not inferred, and cycle-based forecasts are suppressed when inappropriate. Lab collection dates retain their own context.

Prototype boundaries
No live AI, file upload, HealthKit or medical prediction engine. Chat responses are scripted from the enabled sample sources. Missing or excluded data stays unknown. Forecasts are invented UI scenarios. All state lasts for this tab session; reset by refreshing.

Visual and interaction system
Lucide 0.577.0 icons, vendored with license. Local Geist and Source Serif. 44px controls, keyboard support, visible focus and reduced-motion alternatives. Rings transition over 500ms, connections over 220ms, panels over 240ms. Meal photography reuses the existing variations’ assets.
